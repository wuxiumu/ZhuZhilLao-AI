# 01-需求与目标

## 1. 项目背景

当前仓库 `cgos.cc` 下已有一个子项目 `zhuzhiliao/`，它是一个单文件 HTML 的 Web 玩具（竹知了模拟器）。现在需要把 `cgos.cc` 升级为**个人项目展示站点**，并在根目录补充一套基于 PHP + Redis 的后端能力，最终与 `zhuzhiliao` 项目融合展示。

## 2. 改造目标

| 编号 | 目标 | 说明 |
|------|------|------|
| 1 | 根目录展示首页 | `/index.html` 作为项目展示页，重点介绍 `zhuzhiliao`，后续可扩展更多项目 |
| 2 | 流量统计 | 用 PHP + Redis 记录站点访问 PV/UV，并提供接口供前端展示 |
| 3 | 留言板 | 用户输入邮箱和内容即可留言，数据存入 Redis |
| 4 | 聊天接口 | 提供简单的聊天/对话记录接口（REST），数据存入 Redis |
| 5 | 本地开发环境 | 提供 Docker Compose（PHP + Redis），零依赖即可运行 |
| 6 | 文档沉淀 | 所有改造过程写入 `doc/` 目录，按编号管理 |

## 3. 默认方案假设

因用户未明确选择，本改造采用以下默认方案：

- **运行环境**：Docker 本地开发（PHP 8 + Redis 7）。
- **根目录首页**：个人作品集首页，展示 `zhuzhiliao` 项目。
- **聊天**：先做简单留言/对话记录（REST 接口），暂不做实时 WebSocket。
- **现有 Cloudflare Worker**：`zhuzhiliao` 项目自身的计数后端继续保留，根目录展示首页使用新的 PHP + Redis 统计，两套后端互不冲突。

## 4. 目录结构预期

```
cgos.cc/
├── index.html              # 项目展示首页
├── api/                    # PHP 接口
│   ├── stats.php           # 流量统计
│   ├── guestbook.php       # 留言
│   └── chat.php            # 聊天/对话
├── doc/                    # 改造文档
├── docker-compose.yml      # 本地开发环境
├── php.dockerfile          # PHP 镜像构建（可选）
└── zhuzhiliao/             # 原有项目（保留不变）
```

## 5. 约束

- 不破坏 `zhuzhiliao/` 现有文件与部署逻辑。
- 根目录新增文件尽量保持轻量，不引入复杂构建。
- 接口需要做基本的防刷和输入校验。
- 开发过程在独立分支完成（如 `feat/cgos-portal`）。
