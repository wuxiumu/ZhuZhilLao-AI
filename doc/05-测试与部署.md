# 05-测试与部署

## 1. 本地测试

Docker 启动成功后的验证结果：

```bash
# 首页
curl -s http://localhost:8080/ -o /dev/null -w "%{http_code}\n"
# 200

# 健康检查
curl -s http://localhost:8080/api/health.php | python3 -m json.tool
# {
#   "status": "ok",
#   "redis": true,
#   "time_ms": 2.29
# }

# 统计接口
curl -s http://localhost:8080/api/stats.php | python3 -m json.tool
# {
#   "pv": 1,
#   "uv": 1,
#   "today_pv": 1,
#   "today_uv": 1,
#   "online": 1
# }

# 提交留言
curl -s -X POST http://localhost:8080/api/guestbook.php \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","message":"hello from cgos"}'
# {"ok":true,"id":...}

# 获取留言
curl -s "http://localhost:8080/api/guestbook.php?limit=5"
# {"list":[{"email":"test@example.com","message":"hello from cgos",...}]}

# 发送聊天消息
curl -s -X POST http://localhost:8080/api/chat.php \
  -H "Content-Type: application/json" \
  -d '{"name":"visitor","message":"hi there"}'
# {"ok":true,"id":...}

# 获取聊天消息
curl -s "http://localhost:8080/api/chat.php?limit=5"
# {"list":[{"name":"visitor","message":"hi there",...}]}

# Redis 断开时健康检查返回 degraded（无 PHP warning 污染响应）
docker compose stop redis
curl -s http://localhost:8080/api/health.php
# {"status":"degraded","redis":false,"time_ms":...}
docker compose start redis
```

## 2. 常用命令

```bash
# 启动环境
docker compose up --build -d

# 查看日志
docker compose logs -f web

# 进入 PHP 容器
docker compose exec web bash

# 进入 Redis 容器查看数据
docker compose exec redis redis-cli

# 停止环境
docker compose down

# 完全清理（包括 Redis 数据卷）
docker compose down -v
```

## 3. 生产部署建议

### 3.1 Web 服务器

使用 Apache + PHP-FPM 或 Nginx + PHP-FPM。PHP 需要安装 `redis` 扩展。

示例 Ubuntu/Debian 安装：

```bash
sudo apt update
sudo apt install -y php php-redis apache2 libapache2-mod-php redis-server
```

### 3.2 目录权限

确保 `api/` 目录可被 Web 服务器读取，同时建议关闭目录索引：

```apache
Options -Indexes
```

### 3.3 CORS 配置

当前接口响应中已包含 `Access-Control-Allow-Origin: *`，仅适合开发环境。生产环境应改为具体域名，例如：

```php
header('Access-Control-Allow-Origin: https://cgos.cc');
```

### 3.4 Redis 安全

- 生产环境 Redis 应开启认证（`requirepass`）并绑定内网 IP。
- 修改 `api/lib/redis.php` 中的连接参数，支持密码和更严格的配置。

### 3.5 HTTPS

- 生产环境应使用 HTTPS。
- 如果前端和 API 不同源，必须正确配置 CORS 和安全来源。

### 3.6 日志与监控

- 建议将 PHP 错误日志接入日志系统。
- 监控 Redis 内存使用，留言/聊天列表有上限，但长期运行仍会占用空间。

## 4. 已知限制

- 聊天接口为 REST 轮询，非实时 WebSocket；如需实时体验，可后续升级为 WebSocket + Redis Pub/Sub。
- 统计按 IP 去重，在代理或 NAT 场景下可能不够精确。
- 按日 PV/UV 键不会自动清理，需额外定时任务。
