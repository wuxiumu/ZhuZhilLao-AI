### 未改动

- `zhuzhiliao/` 子项目保持原有代码、部署逻辑和 Cloudflare Worker 计数后端不变。

### 优化（2026-08-04 第二轮）

- 删除 `zhuzhiliao/.git`，在 `cgos.cc` 根目录统一初始化新仓库。
- 前端首页优化：
  - 将项目预览区由 `iframe` 改为图片卡片链接，避免触摸/滚动冲突。
  - 增加移动端汉堡菜单与导航高亮。
  - 统计数字增加 loading 动画。
  - 统一表单提交逻辑，增加错误重试与更友好的错误提示。
  - 列表项增加淡入动画，空列表状态更明确。
- 后端优化：
  - 增加 `api/health.php` 健康检查接口。
  - 公共库增加 `sanitize()` 和 `parse_json_input()`，统一输入过滤。
  - 留言与聊天接口使用 `sanitize()` 清理控制字符并限制长度。
  - 优化错误响应，返回 JSON 中的 `error` 字段。
- 配置优化：简化 `.htaccess`，CORS 统一由 PHP 接口设置。

### 第三次改造（2026-08-04）

- CSS/JS 拆分：
  - `assets/main.css`：首页/留言页公共样式。
  - `assets/main.js`：首页/留言页公共脚本。
- 接口地址可配置：新增 `assets/config.js`，通过 `window.CGOS_CONFIG.API_BASE` 设置 API 域名或路径。
- 独立留言页：新增 `guestbook.html`，顶部有滚动 ticker 展示最新留言。
- 聊天弹窗组件：
  - 新增 `assets/chat-widget.css` + `assets/chat-widget.js`。
  - 任意页面引入即可在右下角显示聊天图标和未读消息数。
  - 点击图标展开全屏居中弹窗，支持发送消息、昵称本地保存、未读计数。
- 首页改造：引入拆分后的资源与聊天组件，保留统计/留言/聊天展示区域。
- 文档更新：`README.md` 补充本地 PHP 开发、Docker 使用、聊天组件接入说明。
