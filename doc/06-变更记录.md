# 06-变更记录

## 2026-08-04

### 新增

  - `06-变更记录.md`

### 未改动

### 优化（2026-08-04 第二轮）

- 删除 `zhuzhiliao/.git`，在 `cgos.cc` 根目录统一初始化新仓库。
- 前端首页优化：
  - 将项目预览区由 `iframe` 改为图片卡片链接，避免触摸/滚动冲突。
  - 增加移动端汉堡菜单与导航高亮。
  - 统计数字增加 loading 动画。
  - 统一表单提交逻辑，增加错误重试与更友好的错误提示。
  - 列表项增加淡入动画，空列表状态更明确。
- 后端优化：
  - 增加 `api/health.php` 健康检查接口。
  - 公共库增加 `sanitize()` 和 `parse_json_input()`，统一输入过滤。
  - 留言与聊天接口使用 `sanitize()` 清理控制字符并限制长度。
  - 优化错误响应，返回 JSON 中的 `error` 字段。
- 配置优化：简化 `.htaccess`，CORS 统一由 PHP 接口设置。

### 第三次改造（2026-08-04）

- CSS/JS 拆分：
  - `assets/main.css`：首页/留言页公共样式。

- 接口地址可配置：新增 `assets/config.js`，通过 `window.CGOS_CONFIG.API_BASE` 设置 API 域名或路径。
- 独立留言页：新增 `guestbook.html`，顶部有滚动 ticker 展示最新留言。
- 聊天弹窗组件：
  - 新增 `assets/chat-widget.css` + `assets/chat-widget.js`。
  - 任意页面引入即可在右下角显示聊天图标和未读消息数。
  - 点击图标展开全屏居中弹窗，支持发送消息、昵称本地保存、未读计数。
- 首页改造：引入拆分后的资源与聊天组件，保留统计/留言/聊天展示区域。
- 文档更新：`README.md` 补充本地 PHP 开发、Docker 使用、聊天组件接入说明。

## 2026-08-08：知了快做 MVP

### 新增

- 新增 `zhuzhiliao-mvp/` 独立创作项目，使用 PHP 接口、Redis 临时数据和本地文件持久化。
- 支持自定义知了图片、声音、浏览器录音、实时预览、旋转参数、夜幕色和模拟字数组。
- 支持中文、繁体中文、英文及对应 Demo 默认数据。
- 支持本地草稿、语言和 Tab 状态记忆。
- 支持作品发布、二维码、系统分享、密码访问和原链接编辑更新。
- 支持“我的作品 / 历史作品”、分页、时间/浏览量排序。
- 支持当前 IP 编辑、管理员编辑和管理员删除。
- 增加每 IP 10 个、全站 200 个作品限制。

### 标准版联动

- 根首页和标准版增加“创建我的知了”入口。
- MVP 分享页高度复用标准版的夜景、绳索、竹签和物理效果。
- 默认作品使用标准 3D 竹蝉；自定义图片会关闭 3D 并完全替换默认蝉。
- 修复 Manifest、Service Worker 和 Three.js 静态资源路径。

### 主要修复

- 修复分享 URL 缺少 `/zhuzhiliao-mvp/` 路径。
- 修复新图片后仍能看到默认蝉的问题。
- 修复浏览器录音停止时报空元素异常、无法进入试听的问题。
- 修复低转速作品自动甩无声音/反馈的问题。
- 修复密码作品所有者读取图片和声音返回 403 的问题。
- 修复 favicon、Manifest 和 Three.js 资源 404。

### 分享页配置、海报与本地启动优化
