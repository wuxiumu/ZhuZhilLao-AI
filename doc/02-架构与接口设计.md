# 02-架构与接口设计

## 1. 整体架构

```
浏览器
   │
   ├─ /index.html          项目展示首页（静态 HTML + JS）
   │
   └─ /api/*.php           PHP 接口（流量统计 / 留言 / 聊天）
           │
           └─ Redis 7     数据持久化
```

- 前端展示页与 PHP 接口同源，通过 `fetch` 调用。
- 所有数据存储在 Redis，不引入 MySQL 等数据库，保持轻量。
- `zhuzhiliao/` 子项目保持原有 Cloudflare Pages + Worker 部署不变，仅作为展示对象被首页嵌入和链接。

## 2. 环境

使用 Docker Compose 本地开发：

- `web`：基于 `php:8-apache`，安装 `php-redis` 扩展。
- `redis`：基于 `redis:7-alpine`，持久化到命名卷 `redis-data`。
- 访问地址：`http://localhost:8080/`。
- Redis 暴露端口：`localhost:6379`（便于本地调试）。

## 3. 接口设计

### 3.1 流量统计

- **路径**：`GET /api/stats.php`
- **行为**：记录一次访问（PV + UV + 在线），返回当前统计值。
- **返回**：
  ```json
  {
    "pv": 123,
    "uv": 45,
    "today_pv": 12,
    "today_uv": 8,
    "online": 3
  }
  ```

### 3.2 留言

- **获取**：`GET /api/guestbook.php?limit=20`
  ```json
  { "list": [{ "email": "a@b.com", "message": "hello", "time": 1712345678, "ip": "..." }] }
  ```
- **提交**：`POST /api/guestbook.php`
  - 请求体：`{ "email": "...", "message": "..." }`
  - 限制：邮箱必填且合法；留言 1-500 字；单 IP 1 分钟最多 5 条。

### 3.3 聊天

- **获取**：`GET /api/chat.php?limit=50`
  ```json
  { "list": [{ "name": "匿名", "message": "hi", "time": 1712345678, "ip": "..." }] }
  ```
- **提交**：`POST /api/chat.php`
  - 请求体：`{ "name": "...", "message": "..." }`
  - 限制：消息 1-500 字；单 IP 10 秒最多 3 条。

## 4. 公共库

`api/lib/redis.php` 提供：

- `redis_connect()`：连接 Redis，失败返回 503。
- `client_ip()`：获取真实 IP（支持 `X-Forwarded-For` / `X-Real-IP`）。
- `json_response($code, $data)`：统一 JSON 输出并附带 CORS 头。
- `require_method(...)`：限制允许的 HTTP 方法，自动处理 OPTIONS 预检。
