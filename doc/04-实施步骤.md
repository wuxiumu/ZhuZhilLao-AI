# 04-实施步骤

## 1. 目录创建

```bash
cd /Users/mac/code/git/cgos.cc
mkdir -p api/lib doc
```

## 2. Docker 环境

创建文件：
- `docker-compose.yml`：定义 `web` 和 `redis` 服务。
- `php.dockerfile`：基于 `php:8-apache`，安装 `redis` 扩展。
- `.htaccess`：Apache rewrite 与 CORS 头配置。

## 3. 公共库

创建 `api/lib/redis.php`：
- Redis 连接与错误处理
- 客户端 IP 获取
- 统一 JSON 响应 + CORS
- 方法限制辅助函数

## 4. 接口实现

创建：
- `api/stats.php`：PV/UV/在线统计。
- `api/guestbook.php`：留言提交与查询。
- `api/chat.php`：聊天消息提交与查询。

每个接口均包含：
- 方法限制
- Redis 连接
- 输入校验
- 防刷限速
- 统一 JSON 响应

## 5. 展示首页

创建根目录 `index.html`：
- 与 `zhuzhiliao` 风格一致的暗色国风设计。
- Hero 区展示项目入口。
- 项目介绍区嵌入 `zhuzhiliao` 预览。
- 统计区展示 PV/UV/今日/在线。
- 留言板与聊天区支持前端提交与列表展示。
- 响应式适配移动端。

## 6. 前端接入

在 `index.html` 内使用原生 JS 调用接口：
- 页面加载时请求 `/api/stats.php`。
- 每 30 秒刷新统计。
- 每 10 秒刷新聊天列表。
- 留言和聊天表单提交后自动刷新列表。

## 7. 测试

启动 Docker：
```bash
docker compose up --build -d
```

访问：
- 首页：`http://localhost:8080/`
- 统计：`http://localhost:8080/api/stats.php`
- 留言：`http://localhost:8080/api/guestbook.php`
- 聊天：`http://localhost:8080/api/chat.php`

## 8. 部署建议

- 生产环境应使用 Apache/Nginx + PHP-FPM + Redis。
- 将 `api/` 目录暴露为 Web 可访问，注意关闭目录索引。
- 生产环境应把 CORS 的 `*` 改为具体域名，并配置 HTTPS。
- 如需长期保留每日统计，建议定时任务将过期日键归档或清理。
