# 03-数据模型

所有数据存储在 Redis 的 `0` 号数据库，键名统一以 `cgos:` 为前缀。

## 1. 流量统计

| 键名 | 类型 | 说明 |
|------|------|------|
| `cgos:stats:pv` | String | 总 PV（自增） |
| `cgos:stats:pv:YYYY-MM-DD` | String | 当日 PV |
| `cgos:stats:uv` | HyperLogLog | 总 UV（按 IP 去重） |
| `cgos:stats:uv:YYYY-MM-DD` | HyperLogLog | 当日 UV |
| `cgos:stats:online` | Sorted Set | 在线用户，score 为过期时间戳，member 为 `online:md5(ip+ua)` |
| `rate:guestbook:{ip}` | String | 留言防刷计数器，60 秒过期 |
| `rate:chat:{ip}` | String | 聊天防刷计数器，10 秒过期 |

## 2. 留言

| 键名 | 类型 | 说明 |
|------|------|------|
| `cgos:guestbook` | List | 最近 200 条留言，JSON 字符串，按时间倒序 |

单条记录结构：
```json
{
  "email": "a@b.com",
  "message": "hello",
  "time": 1712345678,
  "ip": "192.168.1.1"
}
```

## 3. 聊天

| 键名 | 类型 | 说明 |
|------|------|------|
| `cgos:chat` | List | 最近 500 条聊天消息，JSON 字符串，按时间倒序 |

单条记录结构：
```json
{
  "name": "匿名",
  "message": "hi",
  "time": 1712345678,
  "ip": "192.168.1.1"
}
```

## 4. 清理策略

- 留言列表通过 `LTRIM` 保留最近 200 条。
- 聊天列表通过 `LTRIM` 保留最近 500 条。
- 在线统计通过 `zRemRangeByScore` 清理过期成员。
- 按日 PV/UV 键不会自动清理，如需长期归档需额外脚本处理。
