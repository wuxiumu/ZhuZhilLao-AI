# 竹知了 · 声音Meme版

同一个甩法，换一副会成梗的声音。

**在线试玩：<https://cgos.cc/zhuzhiliao-meme/>**

> 7种声音主题，赛博朋克风格，甩出你的节奏。

| 主题 | 声音 | 配色 | 特点 |

## 特色

- **赛博朋克界面**：等宽字体、扫描线动画、动态网格背景
- **实时音效**：Web Audio API 处理，转速影响音高
- **主题切换**：一键切换，整个UI跟随变色
- **零依赖**：纯原生 HTML/CSS/JS，单文件部署
- **移动端优化**：触屏友好，响应式布局

## 本地运行

```bash
# 直接打开
open zhuzhiliao-meme/index.html

# 或者用任何HTTP服务器
python3 -m http.server 8000
# 访问 http://localhost:8000/zhuzhiliao-meme/
```

## 技术栈

- Canvas 2D 渲染
- Web Audio API 音频处理
- CSS Grid/Flexbox 布局
- CSS 变量动态主题
- 物理模拟（绳系质点模型）
